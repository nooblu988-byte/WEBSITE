Command System

🎵 /play PLAYBACK

Play a song by name or URL from YouTube, Spotify, SoundCloud & more.

⏸ /pause PLAYBACK

Pause the currently playing track instantly.

▶️ /resume PLAYBACK

Resume a paused song from where it left off.

⏭ /skip PLAYBACK

Skip to the next track in the queue.

⏹ /stop PLAYBACK

Stop playback and clear the entire queue.

🔊 /volume PLAYBACK

Set the playback volume from 0 to 200%.

📋 /queue QUEUE

View the full queue with track info and durations.

🔀 /shuffle QUEUE

Shuffle all tracks in the queue randomly.

🔁 /loop QUEUE

Toggle loop for the current track or entire queue.

🗑️ /remove QUEUE

Remove a specific track from the queue by position.

⏩ /seek QUEUE

Jump to any timestamp in the current track.

🔃 /move QUEUE

Move a track from one position to another in the queue.

🔊 /bassboost FILTER

Apply a deep bass enhancement to the audio.

🌙 /nightcore FILTER

Speed up the track for a classic nightcore effect.

🎵 /8d FILTER

Surround-sound 8D audio effect for headphone users.

🌊 /vaporwave FILTER

Slow, dreamy lo-fi vaporwave audio filter.

🎙️ /karaoke FILTER

Remove vocals from the track for karaoke mode.

🔄 /clearfilter FILTER

Remove all active audio filters and restore defaults.
